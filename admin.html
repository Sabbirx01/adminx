🔐 Admin login

default: admin / admin — এই login শুধু চোখের আড়াল রাখার জন্য, আসল নিরাপত্তা GitHub token-এ (নিচে)। পাসওয়ার্ড বদলাতে এই ফাইলের উপরের DEFAULT_USER/PASS লাইন দুটো এডিট করুন, নইলে token দিয়েই ঢোকা যায় না।

🔑 GitHub token (এটা ছাড়া কিছু সেভ হবে না)

token শুধু আপনার ব্রাউজারে (localStorage) থাকে — কোনো সার্ভারে যায় না। প্রতিটা Approve/Revoke আসলে repo-র keys.json-এ একটা commit, তাই রেকর্ড GitHub-এই থাকে।

➕ নতুন key যোগ করুন

key থেকে শুধু SHA-256 hash সেভ হয় — key নিজে কোথাও লেখা থাকে না।
